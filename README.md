# MRI Chatbot App

A university group project developed as coursework. The application uses a TensorFlow model to classify brain MRI images and includes an OpenAI-powered chatbot that provides educational information about the result.

## Features

- Upload a brain MRI image for experimental classification.
- View the uploaded image and its predicted category.
- Ask the chatbot general questions about the result.
- The chatbot is instructed to provide educational information, not diagnoses or individual treatment advice.

The model predicts one of four categories: glioma tumor, no tumor, meningioma tumor, or pituitary tumor. Uploaded images must be no larger than 16 MB. Uploading a new image removes existing files from the app's upload folder.

## Technology

- Python, Flask, TensorFlow, NumPy, and Pillow
- OpenAI API for chatbot responses
- HTML, CSS, and JavaScript for the web interface

## Setup and run

Run these commands from the repository root:

```bash
python -m venv .venv
```

Activate the virtual environment, then install the dependencies. On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Create a local `.env` file by copying `.env.example`:

```text
OPENAI_API_KEY=your_openai_api_key
FLASK_SECRET_KEY=replace_with_a_long_random_secret
FLASK_DEBUG=0
```

Replace the placeholder values with your own secrets. Keep `.env` private and do not commit it. Start the application from the repository root:

```bash
python src/app.py
```

Open the local URL printed in the terminal in your browser.
